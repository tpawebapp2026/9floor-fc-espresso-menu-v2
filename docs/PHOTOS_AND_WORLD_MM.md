# ပုံအစစ်များ၊ ဖုန်းမီနူးဘားနှင့် နိုင်ငံတကာ အအေးစုံ

## ဖုန်းတွင် ရွေးကြည့်ရန်

အပေါ်ဘက်တွင် မီနူးစာအုပ်၊ နိုင်ငံတကာစတိုင်၊ အကြိုက်ဆုံး၊ အခြေခံပြင်ဆင်မှု ဟူသော ခလုတ်လေးခုရှိသည်။ ဖုန်းဒေါင်လိုက်တွင် နှစ်တန်းပြသည်။ အောက်ဘက်အမြန်မီနူးလည်း ဆက်ရှိသည်။

နိုင်ငံတကာစတိုင်ကို နှိပ်ပြီး **အစုံ / Barista ကော်ဖီ / အအေးစုံ** ကို ရွေးပါ။ အအေးစုံတွင် မူရင်း ၉၉ မျိုးလုံးပါသည်။ Tea Bar၊ Soda Bar၊ Mocktail Bar၊ Smoothie & Frappé၊ Yogurt & Milk၊ Fruit & Refreshers ဟူ၍ ခြောက်လိုင်း ခွဲထားသည်။ နိုင်ငံကို ထပ်ရွေးနိုင်သည်။ ရွေးထားသည့်လိုင်းတွင် မီနူးမရှိသော နိုင်ငံခလုတ်များကို မှိန်ပြထားသည်။ Italian Soda၊ Virgin Mojito၊ Virgin Piña Colada၊ Matcha စတိုင်များသည် လက်ရှိမီနူး ID တူများကိုပဲ ချိတ်ထားသည်။ မီနူးမပွားပါ။ နိုင်ငံအမည်သည် စတိုင်ကို ရည်ညွှန်းခြင်းဖြစ်ပြီး မူရင်းဒေသဖျော်နည်းဖြစ်ကြောင်း အတည်ပြုချက်မဟုတ်ပါ။

## ဓာတ်ပုံများကို နားလည်ရန်

လူတကယ်ရိုက်ထားသော မူရင်းဓာတ်ပုံ ၆၂ ပုံကို ရွေးထားပြီး မီနူး ၂၇၂ ခုအတွက် ချိတ်ဆက်ထားသည်။ မီနူးတစ်ခုစီအတွက် သီးခြားဖျော်ပြီး ရိုက်ထားသော ပုံ ၂၇၂ ပုံဟု မဆိုလိုပါ။ အမျိုးအစားတူ မီနူးများတွင် ကိုးကားပုံတူကို အသုံးပြုထားနိုင်သည်။ AI ဖြင့် ဖန်တီးထားသောပုံနှင့် ကာတွန်းပုံ မပါပါ။

- **ကိုးကားဓာတ်ပုံ** — ဖျော်ရည်အမျိုးအစား၊ ဖျော်ပုံ သို့မဟုတ် အသွင်အပြင်ကို ရည်ညွှန်းသည်။ ဤဆိုင် recipe အတိုင်း လက်တွေ့ဖျော်ထားသောပုံ မဟုတ်ပါ။ အရသာ၊ နို့အမျိုးအစား၊ အပူ/အအေး၊ အလှဆင်၊ အပိုပစ္စည်းနှင့် ခွက်အရွယ် ကွာနိုင်သည်။
- **ပါဝင်ပစ္စည်းပုံ** — သက်ဆိုင်ရာ အသီး/ပစ္စည်းကို ပြထားခြင်းဖြစ်ပြီး ဖျော်ပြီးသားရည်ပုံဟု မဆိုလိုပါ။
- ပုံကိုကြည့်ပြီး ပါဝင်ပစ္စည်း မထပ်ထည့်ပါနှင့်။ မီနူးတွင် ရေးထားသော grams၊ milliliters နှင့် အဆင့်များအတိုင်းသာ လုပ်ပါ။
- မီနူးအသေးစိတ်ပုံအောက်တွင် ပုံရှင်၊ မူရင်းဖိုင်နှင့် လိုင်စင်လင့်များ ပါသည်။ အောက်ခြေရှိ “ဓာတ်ပုံရှင်များနှင့် အသုံးပြုခွင့်” လင့်မှ စာရင်းအပြည့်ကို ကြည့်နိုင်သည်။ ဓာတ်ပုံထဲရှိ ကုန်အမှတ်တံဆိပ်များသည် ဆိုင်နှင့် ပူးပေါင်းထားကြောင်း မဆိုလိုပါ။

ပိုင်ရှင်က မူရင်း recipe image တစ်ပုံ ထည့်ပြီးသားဖြစ်ပါက အဲဒီပုံကို ဦးစားပေးပြသည်။ ယခု ကိုးကားပုံစာရင်းသည် recipe JSON၊ နံပါတ်၊ ပမာဏ၊ အဆင့်များ၊ Favorites ID များကို မပြောင်းပါ။

## Offline နှင့် Update

ပုံများကို app နှင့် တူညီသော hosting မှ ပေးသည်။ ဖုန်းက ပြင်ပဓာတ်ပုံဆိုက်များသို့ ပုံရယူရန် ထပ်ချိတ်စရာမလိုပါ။ ပုံ ၆၂ ပုံကို အရွယ်နှစ်မျိုး WebP အဖြစ် သိမ်းထားပြီး စုစုပေါင်း ၃.၂ MB ခန့်ရှိသည်။ မြင်ရသည့်ပုံများကိုသာ တဖြည်းဖြည်း ဒေါင်းလုဒ်လုပ်သည်။

Service worker အလုပ်လုပ်နေစဉ် အွန်လိုင်းတွင် ကြည့်ပြီးသားပုံများကို cache သိမ်းသည်။ မကြည့်ရသေးသောပုံများကို offline တွင် ရနိုင်မည်ဟု မဆိုလိုပါ။ ပုံမရပါက ကာတွန်းအစား ရှင်းလင်းသောစာသားပြသည်။ Browser က storage ဖျက်ထားပါက cache ပြန်ရယူရန် အင်တာနက်လိုသည်။ မူရင်းဓာတ်ပုံဆိုက်နှင့် လိုင်စင်လင့်ကို သွားဖတ်ရန်လည်း အင်တာနက်လိုသည်။

အက်ပ်ဖွင့်ပြီး အင်တာနက်ရချိန် Update အသိပေးချက်ပေါ်လာပါက “ယခု Update လုပ်မည်” ကို နှိပ်ပါ။ ပြန် install မလိုပါ။ ဤအသိပေးချက်သည် app အတွင်းဖြစ်ပြီး ဖုန်း notification tray သို့ background push မပို့ပါ။ လက်ရှိ hosting လိပ်စာကို ဆရာ့အင်တာနက်မှ မချိတ်နိုင်သော VPN ပြဿနာကို ဓာတ်ပုံထည့်ခြင်းတစ်ခုတည်းဖြင့် ဖြေရှင်းပြီးဟု မဆိုရပါ။

## ပြုလုပ်ပြီးသော စစ်ဆေးမှု

Unit/API tests ၂၇ ခု၊ Pages Chromium browser tests ၉ ခုတွင် မူရင်း recipe ၂၆၀ ခု ထိန်းသိမ်းမှု၊ ဓာတ်ပုံဖိုင် ၁၂၄ ခု ဖွင့်နိုင်မှု/ဖိုင်မှန်ကန်မှု၊ credits၊ offline ပုံဖွင့်မှု၊ ပုံမရလျှင် fallback၊ အအေးမီနူး ၉၉ ခု၏ အုပ်စုခွဲမှု၊ 320–900 px navigation၊ Update activation နှင့် Favorites ထိန်းသိမ်းမှုတို့ ပါသည်။ Physical iPhone/Android Add to Home Screen စမ်းသပ်မှုနှင့် live Admin/Supabase စမ်းသပ်မှု မပြီးသေးပါ။ လက်ရှိသည် reader preview ဖြစ်ပြီး Production deployment မဟုတ်ပါ။

Developer အတွက် ပုံမူရင်းနှင့် လိုင်စင်ကို `photos/sources.tsv`၊ ပုံရှင်စာရင်းကို `photos/CREDITS.md` တွင် မှတ်တမ်းထားသည်။ `scripts/prepare-photos.mjs` သည် စစ်ပြီးသားဖိုင်များကိုသာ အရွယ်လျှော့၍ ချိတ်ဆက်ပေးသည်။ ပုံကိုအလိုအလျောက် ရှာပြီး မစစ်ဘဲထည့်သော script မဟုတ်ပါ။
