# စတိုင်နှင့် V2 အသေးစိတ်ဖျော်နည်း

မူရင်း 272 မီနူးကို မပြောင်းဘဲ 11 မျိုး ထပ်ထည့်ထား၍ စုစုပေါင်း 283 မျိုး ရှိသည်။ မူရင်းပမာဏ၊ နံပါတ်၊ ingredient strings၊ notes၊ steps၊ ID မပြောင်းထားပါ။ Favorites သည် ID အလိုက် ဆက်ရှိသည်။

Matcha သီးသန့်ခလုတ်မှ ဂျပန်၊ ထိုင်း၊ ကိုရီးယား၊ ဗီယက်နမ်၊ အမေရိကန်၊ ထိုင်ဝမ် စတိုင် 10 မျိုး ကြည့်ပါ။ Menu ရှာဖွေမှုသည် Barista နှင့် အအေးစုံ နှစ်လိုင်းလုံးကို ရှာသည်။ စတိုင်စုံခလုတ်နှင့် detail အောက်ပိုင်း ဆက်စပ်စတိုင်များမှ သက်ဆိုင်ရာ မီနူးများကို ဖွင့်နိုင်သည်။ နိုင်ငံအမည်သည် ရည်ညွှန်းစတိုင်ဖြစ်ပြီး မူရင်းနိုင်ငံ၏ အသိအမှတ်ပြုစံဖော်မြူလာဟု မဆိုလိုပါ။

အသစ်များ — Thai Matcha Milk၊ Strawberry Matcha၊ Coconut Matcha၊ Vanilla Matcha၊ Brown Sugar Matcha၊ Hojicha Frappé၊ Thai Coconut Tea၊ Raspberry Cream Soda Float၊ Passion Fruit Virgin Mojito၊ Lychee Oolong၊ Malaysian Teh Tarik။ အားလုံး source-unverified စမ်းသပ်ချက်ဖြစ်ပြီး မရောင်းမီ ပိုင်ရှင်စမ်းဖျော်အတည်ပြုရန် လိုသည်။ ပူသော Teh Tarik ကို အအေးစုံဌာန၏ နို့လက်ဖက်ရည်အုပ်စုတွင် တွေ့နိုင်သည်။

V2 လမ်းညွှန်သည် ingredient တစ်ခုချင်း၏ လက်ရှိပမာဏကို ဖတ်၍ အသေးစိတ်လုပ်ငန်းအဆင့် ဖော်ပြသည်။ တစ်ခွက်ချင်းဖျော်ပါ။ Servings တိုးခြင်းသည် ပြင်ဆင်ရမည့် ingredient စုစုပေါင်းသာ တိုးသည်၊ အပူချိန်၊ blend time နှင့် တစ်ခွက်စာလုပ်ငန်းစဉ်ကို မမြှောက်ပါ။ မူရင်းဖျော်နည်း ခေါက်စာကိုလည်း ဖတ်ပါ။ မူရင်းခွက်မသတ်မှတ်ထားခြင်း၊ ပမာဏအပိုင်းအခြားနှင့် နို့/ရေရွေးချယ်မှု မရှင်းခြင်းကို သတိပြုစာဖြင့်ပြသည်။ ယင်းတို့ကို အတည်ပြုတိကျပြီးဟု မဆိုနိုင်ပါ။ အချိန်နှင့်အပူချိန်အသစ်များသည် လက်တွေ့စမ်းရန် စမှတ်များဖြစ်သည်။

g နှင့် ml သည် တူညီသော unit မဟုတ်ပါ။ သိပ်သည်းဆ calculator တွင် မိမိသုံးသော syrup / milk / purée sample ကို ml တိုင်း၍ g ချိန်ပါ။ density = g/ml၊ g = ml×density၊ ml = g÷density ဖြစ်သည်။ လေပေါက်မကျန်စေဘဲ တူညီသောအပူချိန်တွင် ပြန်တိုင်းစစ်ပါ။ Powder ကို သိပ်သည်းဆမသိဘဲ ml အတိအကျ မရေးပါ။

ကြက်ဥပါ recipe တွင် pasteurized egg product သာသုံးပါ။ ပူသောကော်ဖီလောင်းရုံဖြင့် ပိုးသတ်ပြီးမဟုတ်ပါ။ ဆိုဒါကို အဖုံးပိတ်မရှိတ်၊ blender မကြိတ်ပါနှင့်။ ပူသောအရည်ကို အဖုံးပိတ် blender / shaker မထည့်ပါနှင့်။

ဓာတ်ပုံများသည် လူတကယ်ရိုက်သော ကိုးကားပုံများဖြစ်ပြီး ဆိုင် recipe တစ်ခုချင်း ဖျော်ရိုက်ထားခြင်း မဟုတ်ပါ။ Source / photographer / license ကို detail နှင့် photo-credits.html တွင် ဖတ်နိုင်သည်။

Local Chromium tests သည် iPhone Safari / Redmi K40 အစစ်ပေါ် စမ်းခြင်း မဟုတ်ပါ။ ဖုန်းအမှန်ဖြင့် install၊ offline၊ ပြန် online ဖြစ်ချိန် update စမ်းရန် ကျန်သည်။ OS notification tray push မပါ၊ app အတွင်း Update banner ဖြစ်သည်။ Offline ဖုန်းသည် ပြန်ချိတ်မှ update ရနိုင်သည်။ Admin / Supabase live ချိတ်ဆက်မှု၊ VPN မပါဘဲ ဒေသတွင်းလက်လှမ်းမီမှုနှင့် production deployment ကို အတည်ပြုပြီးဟု မဆိုရ။
