# ပိုင်ရှင်နှင့် အတည်ပြုရန်

အောက်ပါအချက်များကို မခန့်မှန်းဘဲ ထားထားပါသည်။

1. မီနူး 160 ခုတွင် မူရင်းနံပါတ် မပါရှိပါ။ UI တွင် stable recipe ID ပြထားသည်။ Menu 08 ဟူသော ယခင်စကားဝိုင်းအမှတ်ကို လက်ရှိ V8 ဖိုင်မပါဘဲ မချိတ်ထားပါ။
2. မူရင်းမီနူး 260 ခုလုံးအတွက် ပုံအစစ်အတည်ပြုချက် မရှိပါ။ Placeholder သာ ပြထားသည်။ ပိုင်ရှင်ပေးသော beverage photos ကို တစ်ခုချင်း match စစ်ရပါမည်။
3. မူရင်းထဲမှ အများစုသည် စမ်းသပ်ဖျော်နည်းဟု ရေးထားသည်။ စမ်းသပ်အတည်ပြုပြီး recipe များကို owner-tested ပြောင်းရန် လိုသည်။
4. Moka pot ကော်ဖီ/ရေ ပမာဏကို မူရင်းတွင် pot size အလိုက်ဟုသာ ပါရှိသည်။ Exact grams မခန့်မှန်းထားပါ။
5. မူရင်းပါ 6–10 oz / 4–6 oz ကဲ့သို့ range များကို notes တွင် ထိန်းသိမ်းထားသည်။ 8/12/16/22 oz အားလုံးရရှိသည်ဟု မဆိုထားပါ။ Serving multiplier သည် cup-size conversion မဟုတ်ပါ။
6. Vietnamese Egg Coffee ရှိပြီးသား recipe ကို ပြောင်းမထားပါ။ Hot/Iced အသစ်နှစ်မျိုးအတွက် exact formula အတည်ပြုချက် ရပြီးမှ ထည့်ရန် အဆိုပြုစာရင်းတွင် ထားသည်။
7. နိုင်ငံခွဲ view သည် နာမည်မှ ရွေးထားသော style grouping ဖြစ်သည်။ Country of origin authenticity ကို သီးခြားစစ်ဆေးအတည်ပြုထားခြင်း မရှိပါ။
8. Source data ရှိ quantities များထဲက အချို့သည် preparation steps နှင့် တူညီမတူညီ ပိုင်ရှင်လက်တွေ့ စစ်ဆေးရန် လိုသေးသည်။ မူရင်းအတိုင်း ထိန်းထားပြီး ဤအဆင့်တွင် အရသာစမ်းသပ်ပြီးဖြစ်ဟု မဆိုပါ။
