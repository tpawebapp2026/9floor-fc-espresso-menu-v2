# နားလည်လွယ်သော ဖျော်နည်း Update

မီနူး 307 ခု၏ ဖျော်နည်းပုံစံကို ဖုန်းတွင် လိုက်လုပ်ရလွယ်အောင် ပြင်ထားသည်။ မူရင်း recipes.json၊ ပစ္စည်းပမာဏ၊ menu number နှင့် favorites storage မပြောင်းပါ။

- ပင်မဖျော်နည်းတွင် စာပိုဒ်ရှည်များကို အဆင့်တိုများ ခွဲပြသည်။ အမှန်ခြစ်ဖြင့် လိုက်လုပ်နိုင်သည်။
- မူရင်းမီနူးများ၏ ထပ်နေသော ထုပ်ပိုး/အော်ဒါခေါ်ဆိုမှုများကို လိုက်ဖျော်စာရင်းမှ ဖယ်ထားသည်။ မူရင်းစာရင်းကို ဆက်ဖတ်နိုင်သည်။
- အသစ် 24 ခုကို မိမိ ingredient များဖြင့်သာ အမည်၊ ပမာဏ၊ ထည့်စဉ်ကို ပြန်ရေးထားသည်။ Soda ထဲ မဆိုင်သော နို့/cream/Matcha ညွှန်ကြားချက် မပါ။
- Taro နှင့် Matcha အတွက် ရေနွေးကို သီးခြားပြထားသည်။ Foam တစ်ဘူးစာနှင့် topping တစ်ခွက်စာ၊ espresso coffee grounds နှင့် သောက်မည့်ရည်ကို ခွဲရှင်းထားသည်။
- TARE၊ g/ml၊ syrup၊ sauce၊ concentrate၊ purée၊ espresso၊ cold foam၊ microfoam တို့ကို မြန်မာလို သီးခြားဖွင့်ဖတ်နိုင်သည်။
- အသေးစိတ်နည်းစနစ်နှင့် မူရင်းဖျော်နည်းကို အောက်တွင် ဖွင့်ဖတ်နိုင်သည်။ ကြက်ဥပါမီနူးတွင် pasteurized သတိပေးချက်ကို ပင်မနေရာ၌ ဆက်ပြထားသည်။
- အဆင့်ပါပမာဏများသည် မူရင်းတစ်ခွက်/တစ်ဘူးစာ ဖြစ်သည်။ ခွက်အရေအတွက်တိုးထားလျှင် ingredients table စုစုပေါင်းကို ခွဲသုံးရန် ရှင်းပြထားသည်။

ဖျော်နည်းရှင်းလင်းရေး ပြင်ဆင်မှုသာဖြစ်ပြီး အရသာစမ်းသပ်အတည်ပြုပြီးဟု မဆိုလိုပါ။ မူရင်းဖော်မြူလာ၏ မရှင်းလင်းသော ပမာဏများကို မခန့်မှန်းဖြည့်ထားပါ။
