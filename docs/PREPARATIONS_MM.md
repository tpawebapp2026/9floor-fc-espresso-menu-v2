## g နှင့် ml

g သည် အလေးချိန်၊ ml သည် ထုထည်ဖြစ်၍ တန်းတူ မသတ်မှတ်ရ။ Recipe တိုင်းတွင် g နှင့် ရေ၏ ≈ ml ပါသည်။ အသီးအသား၊ အမှုန့်၊ brown sugar နှင့် sauce အတွက် မတိုင်းထားသော density ကို မဖန်တီးထားပါ။ သကြားမှုန့်၏ အချောင်ထုထည်သည် ရည်အချော၏ သိပ်သည်းဆနှင့် မတူပါ။

ရေ၏ conversion သည် 20°C တွင် ρ≈0.9982 g/ml အပေါ် မူတည်သည်။ သကြားဖြူသာ ပါသော 50% w/w syrup အတွက် ခန့်မှန်း ρ≈1.23 g/ml ကို reference အဖြစ် ဖော်ပြသည်။ ဤကိန်းကို အသီးအနှစ်နှင့် sauce တွင် မကူးသုံးရ။ Ingredients ၏ ml များကို ပေါင်း၍ finished yield ဟု မတွက်ရ။

Recipe detail တွင် **g ↔ ml ပမာဏပြောင်းရန်** ကိရိယာ ပါသည်။ အတိုင်းခွက်ကို Zero ပြုလုပ်၊ ကိုယ်သုံးမည့်အပူချိန်ရှိ batch ကို အမြှုပ်မပါအောင် ညီစေပြီး 100 ml sample ၏ အသားတင် g ကို ချိန်ပါ။ ပမာဏနှင့် g ကို ဖြည့်ပြီး လိုသော serving ကို ပြောင်းပါ။ ဥပမာ 100 ml = 123 g ဟု ကိုယ်တိုင်တိုင်းထားလျှင် ρ=1.23 g/ml၊ 30 ml ≈36.9 g ဖြစ်သည်။ ဤဥပမာကို အသီးအားလုံး၏ density ဟု မယူဆရ။ Sample ကို သိမ်းဆည်းမထား၍ batch အသစ်တွင် ပြန်တိုင်းရသည်။

Batch အရေအတွက် 2 ရွေးလျှင် ingredients ၏ g နှင့် ≈ ml နှစ်ခုလုံး တိုးသည်။ ဖျော်နည်းစာသားသည် batch တစ်ခုစာဖြစ်ကြောင်း ရှင်းပြထားသည်။ အစပြုသူအတွက် batch တစ်ခုချင်း ပြုလုပ်ရန် အကြံပြုထားသည်။

## အစားအသောက်ထိန်းသိမ်းမှု

ဤ recipe များကို ရေခဲသေတ္တာမလိုဘဲ ကြာရှည်ထားနိုင်သော canned / shelf-stable products ဟု မယူဆရ။ ထိုနေ့သုံးရန် batch သေးသေးသာ လုပ်ပါ။ ပူသောအစားအစာကို ဘူးငယ်၊ မနက်သောဘူးများတွင် ခွဲ၍ မြန်မြန်အအေးခံပြီး 4°C အောက်ထားပါ။ ပျက်စီးအနံ့ကို မြည်းကြည့်ပြီး ဆုံးဖြတ်ခြင်း မလုပ်ရ။ လုပ်ငန်းသုံး shelf-life၊ pH၊ Brix နှင့် pasteurization လုပ်ငန်းစဉ်ကို စမ်းသပ်အတည်ပြုမထားပါ။

USDA အထွေထွေညွှန်ကြားချက်အရ အအေးလိုအပ်သောအစားအစာကို အပြင်၌ 2 နာရီကျော်ထားလျှင် ပယ်ပါ။ ပတ်ဝန်းကျင် 32°C ကျော်လျှင် 1 နာရီသာဖြစ်သည်။ ဤအချက်သည် recipe တစ်ခုချင်း၏ shelf-life စမ်းသပ်ချက်ကို အစားမထိုးပါ။

## သိမ်းဆည်းခြင်းနှင့် နောက်ပိုင်းပြင်ရန်

JSON catalog schema မပြောင်းထားပါ။ New recipe/category များကို မူရင်း catalog ထဲ append သာလုပ်ထား၍ JSON backup / restore schema ကို ဆက်သုံးနိုင်သည်။ Source generator scripts/expand-preparations.py သည် ID ထပ်နေပါက overwrite မလုပ်ဘဲ ရပ်သည်။ မူရင်း 260 recipes ၏ field အားလုံးမပြောင်းကြောင်း SHA256 regression စမ်းသပ်ချက် ပါသည်။ Favorites / recent / theme keys နှင့် ID များကို မပြောင်းထားပါ။

Live Admin / Supabase မချိတ်ရသေး၍ Pages preview တွင် app ထဲမှ publish မလုပ်နိုင်သေးပါ။ သီးခြား production approval မရမချင်း preview အဖြစ်သာ ကိုင်တွယ်ရမည်။ Physical iPhone / Redmi Add to Home Screen စမ်းသပ်ချက်များသည် လိုအပ်နေဆဲ ဖြစ်သည်။
